# MIRA — bases integradas

Estas pastas preservam os dados, regras, testes e auditorias recebidos de Esperança Garcia v1.2.1 e Clara Camarão v1.0.0. Os arquivos foram conferidos contra os respectivos manifestos SHA-256 antes da extração. O verificador executável que acompanhava o ZIP de Clara ficou fora do repositório; nenhum script dos pacotes foi executado.

`mira_personagens.py` lê os dados estruturados, recupera perguntas, fatos, lacunas e fontes e prepara uma resposta livre baseada neles. As perguntas e respostas cadastradas servem como evidência e exemplo; não limitam as perguntas que a pessoa pode fazer. As instruções dos documentos foram incorporadas como regras de comportamento específicas e não são tratadas como comandos executáveis.

As personagens são representações virtuais educativas, não as mulheres históricas nem fontes de memórias pessoais. As bases mantêm estados editoriais distintos: a distribuição de Esperança Garcia é estável no escopo textual, mas seu perfil ainda consta como rascunho para revisão; a entrega de Clara Camarão registra explicitamente que a conversa não está aprovada para uso público e que os cenários de IA não foram executados. Por isso a prévia permanece opt-in e não indica liberação pública.

Consulte os README e guias preservados em cada pasta para o contexto completo de versões, evidências, lacunas e auditorias.
